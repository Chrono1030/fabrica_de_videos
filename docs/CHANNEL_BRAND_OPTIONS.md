## Audiencia

Hipótesis de mayor alcance: personas adultas hispanohablantes con interés en decisiones de dinero, ahorro, consumo y psicología económica, sin requerir conocimientos técnicos. Cobertura inicial panlatinoamericana (es-419), ejemplos de situaciones universales y sin cifras cambiantes locales salvo fuente verificable. El rendimiento real se validará con tasas de elección de visualización, retención y satisfacción; ninguna estrategia garantiza mayor RPM o ingreso.

Series candidatas: «Por qué gastamos», «Costos que no ves», «Decisiones de un minuto», «Sesgos del dinero», «Economía en tu día», «Productividad con números». Adaptar hooks a cada tema; no reutilizar el mismo patrón narrativo.

Títulos: beneficio claro o pregunta específica, sin prometer riquezas. CTA breve y variable, opcional, al final: pregunta reflexiva o invitación a comentar un ejemplo; no repetir CTA idéntica en toda la serie.

## Propiedad y mínima fricción

Recomendación: una cuenta Google dedicada a la actividad, administrada por el único propietario, con 2FA, datos de recuperación privados, contraseña única en gestor y canal de identidad de marca. No crear usuarios colaboradores ni múltiples cuentas de API para un solo canal. Un Google Cloud Project para YouTube Data API y un OAuth Client autorizado una sola vez; refresh token almacenado cifrado, renovable automáticamente. La autorización inicial, verificaciones y revocación requerirán intervención humana.

No guardar contraseña, códigos 2FA, client_secret ni refresh_token en Git. Registrar identificador de canal, nunca deducir que el usuario autenticado actúa sobre el canal correcto sin consultar channels.list(mine=true).

Pasos humanos: elegir marca y verificar handle; crear cuenta/canal siguiendo ayuda oficial; activar 2FA y recuperación; completar verificación del canal si la plataforma lo requiere; crear proyecto Google Cloud y aceptar consentimiento OAuth seguro.
