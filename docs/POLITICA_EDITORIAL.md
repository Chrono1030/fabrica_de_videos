# Política editorial para contenido autónomo

El canal trata ideas originales de economía y productividad. Los libros son **inspiración temática**, no material a traducir, narrar, resumir capítulo por capítulo o adaptar. Evitar citas extensas, ejemplos característicos, secuencias de capítulos, marcas que sugieran patrocinio y voces imitadas sin licencia.

## Estructura
Gancho propio → problema concreto → ejemplo cotidiano original → explicación con matices → conclusión. No dar asesoramiento personalizado, inducir compras de activos, prometer rendimientos ni afirmar verdades económicas absolutas sin justificación.

## Control de calidad
- Todo valor, fecha, porcentaje o afirmación factual sensible necesita respaldo trazable, o debe ser hipotético y reconocible.
- Diferenciar correlación de causalidad e identificar las excepciones relevantes.
- Guardar prompts, modelo, referencias, costo y SHA del guion final.
- Comparar guiones y ejemplos con históricos mediante hashes y similitud semántica.
- Incorporar comprobación semántica **independiente**; las reglas regex actuales son preliminares y no bastan para publicación.
- Si falta evidencia, licencia o permisos: BLOCKED_CONTENT / QUARANTINED.

La reutilización de la estética, iconos o plantillas técnicas **no** autoriza contenido editorial repetitivo: exigir estructura, explicación y ejemplos diferenciados para cada entrega.
