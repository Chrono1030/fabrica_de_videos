# Decisiones de arquitectura

| ID | Elección | Motivo |
|---|---|---|
| ADR-001 | Conceptos originales, no adaptación de libros | Menor riesgo de copyright y mayor originalidad |
| ADR-002 | es-419 | Alcance latinoamericano y TTS neutral |
| ADR-003 | Piper es_MX inicial; Kokoro evaluable | Voz local; revisar licencias y naturalidad |
| ADR-004 | Pillow/SVG/FFmpeg | Costo marginal mínimo; visuales deterministas |
| ADR-005 | GPT Responses API con salidas estructuradas | Guiones automáticos y costo medible |
| ADR-006 | Sin APIs macroeconómicas en MVP | Enfoque atemporal, menos dependencias |
| ADR-007 | Uptime Kuma y logs internos | Alertas sin construir otro panel |
| ADR-008 | n8n + SQLite | Orquestación y persistencia sencilla |
| ADR-009 | YouTube primero; TikTok tras auditoría | Cumplir condiciones de plataforma |
| ADR-010 | Publicación con fail-closed | Evitar errores irreversibles |
